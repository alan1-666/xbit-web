# Code Taste Review

## Review Lens

- Does the changed module own this behavior?
- Is the abstraction justified by real duplication or complexity?
- Are loading, empty, error, and disabled states clear?
- Is the test or manual verification proportional to risk?
- Did the change mix styling, API, and state behavior unnecessarily?
